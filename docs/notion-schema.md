# Notion「学習テーマデータベース」

- 場所: Notion「キャリア開発」配下
- URL: https://app.notion.com/p/9bbd11f66438418fadfa0140f43c356c
- データソース: `collection://73f5d8cc-b330-4703-b39e-dd0fe05717ff`
- 説明: 毎日クイズの出題テーマ。優先度・状態・出題方針を編集すると、翌朝の出題から反映される。

| プロパティ | 種類 | 内容 |
|---|---|---|
| テーマ名 | タイトル | |
| 優先度 | セレクト（高 / 中 / 低） | 出題比率 高:中:低 = 3:2:1 |
| 状態 | セレクト（有効 / 一時停止） | 一時停止にすると出題されない |
| 出題元 | テキスト | ナレッジDBのタグ、参考URL、リポジトリなど |
| 出題方針メモ | テキスト | 難易度や切り口の指示（例: 基礎は理解済み、応用寄りで） |

テーマの中身（どのテーマが有効か等）は Notion が正で、このリポジトリでは管理しない。

「キャリアナレッジの復習」テーマは、Notion「📙 キャリアナレッジ データベース」の最近のページから出題する。
